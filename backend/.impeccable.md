## Design Context

### Users
A developer uploading card data during development. They need a fast, transparent way to configure an endpoint, select multiple images, enter per-card metadata, and submit or retry individual cards.

### Brand Personality
Minimal, calm, focused, practical.

### Aesthetic Direction
A dark, quiet developer utility with restrained contrast, cool blue-gray surfaces, crisp typography, and no decorative noise. Standalone HTML with no framework or build step.

### Design Principles
- Keep the upload workflow obvious: configure, review, submit.
- Make per-image metadata editing easy to scan and navigate by keyboard.
- Use restrained dark surfaces and clear focus states rather than heavy decoration.
- Give every request a visible state and actionable error feedback.
